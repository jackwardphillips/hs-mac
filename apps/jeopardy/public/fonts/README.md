# Game typography

These unmodified fonts are distributed under the SIL Open Font License 1.1;
the corresponding copyright notices and licenses are included alongside them.

- Oswald variable (200–700): categories, values, scores and display headings.
  Source: https://github.com/google/fonts/tree/main/ofl/oswald
- Libre Baskerville upright variable (400–700): clue text, set at weight 600.
  Source: https://github.com/google/fonts/tree/main/ofl/librebaskerville

Retrieved 2026-09-10. These are free visual approximations, not the show's
Korinna/Swiss typefaces. Fonts are served locally, with no external font requests.
The supplied logo and drawn player names remain unchanged.
